# Orchestra - Modern Electron Port Plan

## Overview

Port the Orchestra regex visual editor from Electron 13 to modern Electron 33+, replacing all deprecated APIs, updating dependencies, modernizing the build system, and cleaning up code quality.

---

## Phase 1: Project Structure & Build Modernization

### 1.1 Update `package.json`
- Upgrade `electron` from `^13.1.9` → `^33.0.0`
- Upgrade `electron-builder` from `^22.11.7` → `^25.0.0`
- Remove `electron-packager` (replaced by electron-builder)
- Remove `gulp`, `gulp-cli`, `gulp-uglify` (unused in actual build)
- Remove `electron-installer-dmg` (electron-builder handles this)
- Remove `request` (deprecated, use built-in `fetch`)
- Remove `natives` (deprecated, no longer needed)
- Remove `mv`, `plist`, `sloc` (not needed)
- Upgrade `monaco-editor` from `^0.9.0` → `^0.52.0`
- Keep: `concerto-compiler`, `regulex`, `regexpu`, `core-js`, `jsonfile`, `lodash.template`
- Add: `@electron/remote` (not needed since we're doing full IPC, skip)
- Add: `less` as devDependency (currently requires global install)

### 1.2 Modernize Build System
- Replace `build.js` with `electron-builder` config in `package.json`
- Use `electron-builder` for all platform builds (Mac/Linux/Windows)
- Remove `configure.sh` / `config.sh` (no longer needed)
- Update `.travis.yml` or remove it (if CI isn't being used)
- Add npm scripts: `start`, `build`, `pack`, `dist`

**Files to modify:**
- `package.json`
- `build.js` → simplify or replace
- `.gitignore`

## Phase 2: Main Process (`winserver/main.js`)

### 2.1 Security Hardening
- Set `nodeIntegration: false`
- Set `contextIsolation: true`
- Remove `enableRemoteModule: true`
- Keep preload script path

### 2.2 Move All Node Operations to Main Process via IPC
Add IPC handlers for operations currently done in renderer:

| Operation | Current Location | New IPC Channel |
|-----------|-----------------|-----------------|
| `fs.readFile` | `editor/ui/file.js` | `file:read` |
| `fs.writeFile` | `editor/ui/file.js` | `file:write` |
| `dialog.showOpenDialog` | `editor/ui/dialogs.js` | `dialog:open` |
| `dialog.showSaveDialog` | `editor/ui/dialogs.js` | `dialog:save` |
| `dialog.showMessageBox` | `editor/ui/dialogs.js`, `editor/ui/window.js` | `dialog:message` |
| `shell.openExternal` | `editor/ui/menu.js` | `shell:open-external` |
| `Menu.buildFromTemplate` | `editor/ui/menu.js` | Move to main process |
| `Menu.setApplicationMenu` | `editor/ui/menu.js` | Move to main process |
| `getCurrentWindow().minimize/close/maximize/etc` | `editor/ui/window.js` | `window:minimize`, `window:close`, `window:maximize`, etc. |
| `getCurrentWindow().setDocumentEdited` | `editor/ui/file.js` | `window:set-edited` |
| `getCurrentWindow().setRepresentedFilename` | `editor/ui/console.js` | `window:set-represented-filename` |
| `getCurrentWindow().openDevTools` | `editor/ui/dev-tools.js` | `window:open-devtools` |
| `app.getName()` | `editor/ui/menu.js` | `app:get-name` |
| `clipboard.writeText` | `editor/ui/ui.js` | `clipboard:write-text` |

### 2.3 Move Menu to Main Process
- Define the full application menu in `main.js` (currently in `editor/ui/menu.js`)
- Send menu-related events back to renderer via IPC
- Handle keyboard shortcuts in main process

## Phase 3: Preload Script (`winserver/preload.js`)

Rewrite to expose a safe, limited API via `contextBridge.exposeInMainWorld`:

```js
// Exposed API shape:
window.electronAPI = {
  // File operations
  readFile: (path) => ipcRenderer.invoke('file:read', path),
  writeFile: (path, data) => ipcRenderer.invoke('file:write', path, data),
  
  // Dialogs
  showOpenDialog: (options) => ipcRenderer.invoke('dialog:open', options),
  showSaveDialog: (options) => ipcRenderer.invoke('dialog:save', options),
  showMessageBox: (options) => ipcRenderer.invoke('dialog:message', options),
  
  // Window controls
  minimizeWindow: () => ipcRenderer.send('window:minimize'),
  maximizeWindow: () => ipcRenderer.send('window:maximize'),
  closeWindow: () => ipcRenderer.send('window:close'),
  toggleFullScreen: () => ipcRenderer.send('window:toggle-fullscreen'),
  setDocumentEdited: (edited) => ipcRenderer.send('window:set-edited', edited),
  setRepresentedFilename: (name) => ipcRenderer.send('window:set-represented-filename', name),
  openDevTools: () => ipcRenderer.send('window:open-devtools'),
  
  // Shell
  openExternal: (url) => ipcRenderer.invoke('shell:open-external', url),
  
  // Clipboard
  writeClipboardText: (text) => ipcRenderer.invoke('clipboard:write-text', text),
  
  // App info
  getAppName: () => ipcRenderer.invoke('app:get-name'),
  getPlatform: () => process.platform,
  
  // Theme
  onThemeChange: (callback) => ipcRenderer.on('change-theme-to', (_, mode) => callback(mode)),
  
  // Help window
  onHelpWindowOpenRef: (callback) => ipcRenderer.on('help-window-open-ref', (_, ref) => callback(ref)),
  
  // Menu events from main process
  onMenuAction: (callback) => ipcRenderer.on('menu-action', (_, action) => callback(action)),
}
```

**Files to modify:**
- `winserver/preload.js`

## Phase 4: Renderer Code Migration

### 4.2 `editor/globals/storage.js`
- No changes needed (pure state variables)

### 4.3 `editor/ui/window.js`
- Replace `OrchestraWindow.close()` → `electronAPI.closeWindow()`

- Replace `OrchestraWindow.isMaximized()` → needs IPC or cached state

### 4.5 `editor/ui/dialogs.js`
